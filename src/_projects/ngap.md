The *Next Generation Avionics Platform* (NGAP) is a brand-new avionics ecosystem that will be modular and backwards-compatible.

While HYDRA, PHOENIX and ARGUS have all been built as board-specific projects, *NGAP* is designed using a system-first approach. It is implemented in three distinct major releases:

## Release 0
The first release of the NGAP system exists as a proof of concept, providing the “bare minimum” expected of an avionics suite, i.e. configurable deployment altitudes, capable of using redundant boards, and logs internal states of all connected devices.

The three boards present in this release are: Flight Controller (FC), Recovery/Pyro (REC), and Logger/Telemetry (LOG). Approaching the tail end of release 0, antenna tracker support will be initiated to ensure effective capture of telemetry packets.

## Release 1
The second release exists as a fully functional avionics system, expanding the capabilities of NGAP and further refining upon Release 0 with additional features. Release 1 is planned to add power monitoring, and a sensor board to the NGAP ecosystem for further monitoring and sensing of onboard systems and to allow for the team to check flight logs against created models.
